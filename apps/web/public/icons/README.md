# PWA icons

Replace these **placeholder** PNGs before launch. Keep the filenames and sizes so the web app manifest keeps working.

| File | Size | Purpose |
| --- | --- | --- |
| `icon-192.png` | 192×192 | Standard install icon |
| `icon-512.png` | 512×512 | High-res install / splash |
| `icon-maskable-512.png` | 512×512 | Android maskable (safe zone ~80% centre) |

Brand colours: navy `#0F1545`, orange `#FF7500`.

Manifest entry: `apps/web/src/app/manifest.ts`.
